# Ticket Press · 티켓 프레스

> 대회 기념품부터 수업 보상까지, 일련번호가 자동으로 찍히는 인쇄용 교환권 제작 도구

## 무엇을 해결하나

학교스포츠클럽 대회 기념품 110매를 배부하려면 교환권이 필요합니다. 한글에서 메일머지로 일련번호를 매기고, 디자인을 새로 짜고, 교환 명부를 따로 만들어야 합니다. 이 과정을 브라우저에서 한 번에 끝내도록 만들었습니다.

| | 기존 방식 | Ticket Press |
|---|---|---|
| 일련번호 | 한글 메일머지 설정 | 수량만 입력하면 자동 |
| 디자인 | 매번 새로 제작 | 6종 테마 중 선택 |
| 학생 이름 | 수기 작성 | 명단 붙여넣기로 인쇄 |
| 교환 관리 | 별도 명부 작성 | CSV 대장 자동 생성 |

---

## 주요 기능

- **일련번호 자동 발행** — 최대 600매, 접두어 지정 가능 (`OSB-26-001`)
- **용도 프리셋 7종** — 굿즈 교환권 / 리워드 티켓 / 찬스 카드 / 과제 패스권 / 도서 교환권 / 체험 이용권 / 참가 확인권
- **디자인 테마 6종** — 라이트 3종(토너 절약) · 다크 3종(고급 인쇄)
- **명단 발행** — 엑셀에서 복사한 명단을 붙여넣으면 학반·이름이 미리 인쇄됨
- **위조방지 검증코드** — 대회명과 번호로 계산한 2자리 코드
- **교환 확인 대장** — CSV 내려받기 (엑셀 바로 열림, 한글 깨짐 없음)
- **학교 마크 교체** — 다른 학교에서도 그대로 사용 가능
- **A4 인쇄 최적화** — 한 장에 4매, 절취선 포함

---

## 사용법

1. 위 주소에 접속하거나 `index.html`을 내려받아 더블클릭합니다.
2. 왼쪽 패널에서 대회명·일자·교환 품목·수량을 입력합니다.
3. 용도와 디자인 테마를 고릅니다.
4. **인쇄하기** 또는 `Ctrl` + `P`.

### 인쇄 설정 (중요)

| 항목 | 설정값 |
|---|---|
| **배경 그래픽** | **켜기** ← 끄면 색이 인쇄되지 않습니다 |
| 용지 | A4 · 세로 |
| 여백 | 없음 |
| 배율 | 100% |

「배경 그래픽」은 크롬 인쇄 창의 **「설정 더보기」**를 펼쳐야 보입니다.

### 재단

교환권 사이 빈 공간의 가운데를 자릅니다. **오른쪽 세로 점선은 자르지 마세요** — 교환 시 뜯어서 회수하는 스텁입니다.

## 교과 수업 활용

체육 대회 외에 교과 수업의 보상 활동에도 그대로 쓸 수 있습니다. 바꿀 칸은 세 개뿐입니다.

- **대회명** → 수업·단원 이름 (예: `3학년 과학 탐구활동`)
- **용도** → 리워드 티켓 / 찬스 카드 / 과제 패스권
- **교환 품목** → 학생이 받는 것 (예: `자리 선택 1회`)

번호 접두어를 과목별로 나누면(`SCI-26`, `KOR-26`) 대장을 합쳐도 출처가 구분됩니다.

## 기술 구성

| 항목 | 내용 |
|---|---|
| 스택 | 단일 HTML (패턴 A) · 외부 의존성 없음 |
| 배포 | GitHub Pages |
| 서체 | IBM Plex Sans KR · IBM Plex Mono (Google Fonts) |
| 저장 | `localStorage` — 입력값이 브라우저에 보관됨 |
| 서버 통신 | 없음 |

**개인정보 안내** — 모든 처리가 사용자 브라우저 안에서만 이루어집니다. 학생 명단을 포함해 어떤 데이터도 외부로 전송되지 않으며, 서버에 저장되지 않습니다.

인터넷 연결은 Google Fonts를 불러오는 용도로만 사용합니다. 오프라인에서도 동작하지만 서체가 기본 글꼴로 대체됩니다.
